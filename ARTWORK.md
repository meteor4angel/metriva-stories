# Story 02 artwork

Mode: built-in Image Generation tool, using the user’s approved Story 02 board, retained unchanged as assets/story02-approved-reference.png.

Final assets: assets/library-{evelyn,ada,theo,eleanor}-frames.png; assets/library-{reading,listening,archive,workshop,chamber}-painted.png; assets/library-evidence-atlas.png.

Prompt set: preserve each approved character’s facial identity, hair, clothing and warm painterly anime rendering. Create transparent 2×2 animation sheets with neutral, closed-eye blink, speaking and thoughtful frames in matching waist-up poses. No source-board portrait crop, UI, labels or backdrop in character sheets. Create five separate wide library rooms based on the board’s architectural and lighting references, with appropriate furniture and no people or oversized foreground characters. Create a 4×4 ivory-background atlas of isolated library evidence objects, with readable clue information supplied in HTML rather than relying on generated handwriting. The browser displays individual generated animation frames and evidence tiles from these purpose-built sheets.

Story 01’s assets and its previous artwork documentation remain represented by the retained v0.6.1 build and screenshots.
