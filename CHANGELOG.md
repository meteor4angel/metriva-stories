## v0.7.2 — voice opening pause

Added a 900 ms pause before each spoken line and replay, with preloading. Advancing, muting or closing cancels pending playback.

## v0.7.4 — replaceable audio

Renamed all 76 dialogue files by chapter, speaker and purpose. Added AUDIO-SCRIPTS.csv with the exact spoken text for every filename. The player now preloads each file, waits one second before calling play, and holds for one second after playback ends. Advancing, replaying, muting or closing cancels either pause.
