# Story 6 — interactive valve route

Chapter 2's route puzzle uses `assets/story06-pump-valve-chart-puzzle.png`, a puzzle-only edit of the existing `assets/story06-pump-valve-chart-detail.png`. The evidence chart remains unchanged and is available through **View original chart**. The new image preserves the parchment, printed names, all valve centers, blue pipes, workshop background, and lighting while removing the pre-drawn red solution route. It was made with the built-in image-generation tool and copied into the project at 1672 × 941 pixels.

The built-in image edit prompt was:

> Use case: precise-object-edit. Edit target: the supplied Story 6 valve-chart detail image. Make a puzzle-only version preserving the EXACT composition and all four valve positions and names. Remove only the red solution arrows, route lines, and red circles. Reconstruct the tan parchment and original neutral pipe strokes beneath them. Keep blue branches, labels, workshop wood, tools, lighting and 1672×941 landscape proportions intact. No UI, no glow, no new pipe network.

The `interactive-route` presentation is declared entirely in `stories/story-06.json`. Its locations use pixel coordinates in the image's intrinsic coordinate system. Nine selectable valve wheels include five plausible wrong stops. The `network` lists the physical pipe segments and junctions visible on the chart; the engine finds a connecting route between each successive selection. It renders the image and overlays inside one SVG viewBox. Chosen connections trace amber without validating partial choices. Only a correctly submitted complete route receives a brief emerald confirmation. Players select exactly four stops and can remove any selection, undo the last, or reset. The correct sequence remains the puzzle's `answer` array, and existing investigation gates, hints, save/export, and completion logic remain in force. Opening the original chart keeps the puzzle mounted underneath; X, Back, and Escape return to it.

Future stories can reuse the presentation with another chart image, answer items, optional `decoys`, `choiceOrder`, locations, and a `network` of SVG pipe edges. Junctions may connect pipes without becoming selectable valves. The engine validates choice identities, on-image coordinates, connected pipe geometry, and the referenced image dimensions. The older all-pairs `connections` format remains supported for existing story definitions.
